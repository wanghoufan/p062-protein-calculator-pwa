# 风险与未验证事项

- SW 首次安装需下载约 6.75MB 预缓存，慢速线路下可能耗时数分钟（Note 11 5G 实测约 201 秒）；安装完成前离线不可用，测试时不得在 installing 阶段断网，否则 install 失败。
- 工作区若再有构建脚本改动，推送前需复核 diff，保留既有历史，禁止覆盖远端或删除 `.git`。
- 改名后旧 GitHub Pages 项目页不会自动跳转；需要向朋友发送新地址，本地浏览器数据按域名隔离，旧网页本地数据不自动迁移。
- 027 测试中 Note 11T Pro+ 访问旧线上地址出现“网络故障”，2026-10-27 晚复测新地址已不可复现；朋友所在网络与弱网环境下的可用性仍未确认。
- iPhone Safari 加载、添加到主屏幕、离线行为均未验证；首次发布尚未用户签收。
- 用户明确要求暂不处理“修改后立即关闭可能赶不上延迟保存”的小问题；该问题未经复现，不要当成已验证缺陷。
- 本地存储清理或换设备可能丢失数据；没有云端同步。
